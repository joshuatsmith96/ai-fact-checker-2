## Option 1: The Punchy, Developer-Focused Remake

# **Gemini-Powered AI Fact-Checker** 🔍

A practical, open-source web application that integrates the **Gemini 2.5 Flash API** with a modern **React** frontend to demonstrate real-time, AI-assisted fact verification. Hosted entirely on **Render**, this project is an end-to-end example of bringing AI capabilities into a production-ready web stack.

---

## **Key Features & Tech Stack**

### **🚀 Functionality**

- **AI-Assisted Verification:** Takes user-submitted claims and provides a summary and accuracy rating from the AI.
- **Full-Stack Example:** A clean separation between the React frontend and a lightweight **Node.js/Express** backend.
- **Cost-Effective Design:** Intentionally utilizes the zero-cost usage tier of Gemini 2.5 Flash to ensure the project remains free for experimentation and learning.

### **🛠️ The Stack**

| Layer          | Technologies                                       | Notes                                                         |
| :------------- | :------------------------------------------------- | :------------------------------------------------------------ |
| **Frontend**   | **React**, Fetch API, Modern Component Design      | Fast, responsive interface for submitting and viewing claims. |
| **Backend**    | **Node.js**, **Express**, **Gemini 2.5 Flash API** | Handles API requests and logic for fact-checking.             |
| **Deployment** | **Render** (Frontend & Backend Services)           | Seamless, full-stack hosting and environment configuration.   |

---

## **⚠️ Important Note: Proof of Concept**

This application is a **proof of concept** for demonstrating AI integration—it is **not a substitute for professional research**. The accuracy is dependent on the specific model used (Gemini 2.5 Flash) and should not be relied upon for critical information.

---

## **💡 Get Started**

This project is a perfect educational tool showcasing **cost-free, full-stack AI integration**. Dive into the code to learn:

- How to configure and secure an API key with environment variables.
- Structuring a scalable React frontend with an Express backend.
- Configuring **CORS** for a split-deployment architecture.

**Clone the repo and run locally with `npm run dev` to see it in action!**

## Option 2: The Concise, Marketing-Focused Remake

# **AI Fact-Check Demo: Full-Stack Gemini Integration**

Instantly verify factual claims with this experimental web application. Built on **React** and powered by **Gemini 2.5 Flash**, this project provides a clear blueprint for integrating generative AI into modern web development workflows. **Hosted on Render.**

---

### **How it Works**

1.  A user enters a claim (e.g., "Mount Everest is the tallest mountain in the world.").
2.  The React frontend sends the request to the Node/Express backend.
3.  The backend queries the **Gemini 2.5 Flash API**.
4.  The AI returns a verdict and an explanation.

### **Key Highlights**

| Focus Area       | Detail                                                                             |
| :--------------- | :--------------------------------------------------------------------------------- |
| **Model**        | **Gemini 2.5 Flash** (Selected for zero-cost usage tier).                          |
| **Architecture** | **React** (Frontend) + **Node/Express** (Backend).                                 |
| **Frameworks**   | **MUI** (style framework)                                                          |
| **Deployment**   | **Render** (Easy, full-stack deployment setup).                                    |
| **Goal**         | **Education** and showcasing cost-effective AI enhancement for public information. |
